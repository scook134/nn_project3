# Technical Report: Discrete Probabilistic Time-Series Forecasting on ETTh1

## 1. Introduction

Standard probabilistic forecasting often models each future observation with a Gaussian distribution parameterized by a predicted mean and variance. This is convenient, but restrictive: a Gaussian is unimodal and symmetric, so it cannot naturally express multiple distinct plausible futures. For ambiguous time-series dynamics, that limits the shape of the predictive uncertainty.

The discrete notebook addresses this by turning forecasting into a categorical prediction problem. Instead of directly regressing a continuous value, the normalized signal is quantized into 128 bins, and the model predicts the next bin index. Each time step becomes a token, so forecasting becomes next-token prediction. This creates a direct connection to language models: the model learns `P(next token | previous tokens)`, but the tokens represent quantized signal levels rather than words.

## 2. Dataset and Preprocessing

Both notebooks use `ETTh1.csv` and forecast the univariate `OT` signal. The preprocessing pipeline is the same in both:

- extract `df["OT"]` as a `float32` array
- standardize the full series with its global mean and standard deviation
- subsample by a factor of 10
- build overlapping one-step-ahead windows

The saved notebook outputs report:

- subsampled length: `1742`
- window length: `T = 200`
- number of windows: `N = 5000`
- train/test split: `4000 / 1000`
- conditioning context: `T_train = 100`

For each sampled window, `X` contains the first `T` values and `Y` contains the next `T` values, so the models learn the one-step-ahead autoregressive mapping `X[:, t] -> Y[:, t]`.

## 3. Quantization

The discrete notebook uses `NUM_BINS = 128` uniform bins. Quantization is implemented by scaling values to `[0, 1]`, multiplying by 128, taking the floor, and clipping to `[0, 127]`. Dequantization maps each token back to the center of its bin.

The executed notebook sets:

- `train_min = series_sub.min()`
- `train_max = series_sub.max()`

Although the comments note that train-only bounds would be preferable, the saved run uses the full subsampled series range. The notebook output reports:

- unique bins used: `121`
- first 20 token indices: `[89, 62, 56, 63, 64, 73, 80, 60, 66, 85, 89, 85, 85, 89, 89, 79, 106, 86, 91, 91]`

This quantization step is the key conceptual shift: the continuous signal is converted into a finite token vocabulary, enabling discrete sequence models.

## 4. Model Design

The original notebook implements Gaussian autoregressive baselines:

- `RNN`
- `LSTM`
- `LSTMTransformer`

These models take continuous inputs and predict a Gaussian mean and standard deviation at each time step, with the standard deviation forced positive via `softplus`. Forecasts are generated by sampling from the predicted Gaussian.

The discrete notebook implements four token-based architectures:

- `DiscreteRNN`
- `DiscreteLSTM`
- `DiscreteTransformer`
- `DiscreteLSTMTransformer`

The saved training and evaluation cells actually run:

- `DiscreteRNN`
- `DiscreteLSTM`
- `DiscreteLSTMTransformer`

All discrete models use the same high-level pattern:

- integer token inputs
- learned embeddings through `nn.Embedding`
- a sequence model over embeddings
- a linear output head producing logits over 128 bins

The `DiscreteTransformer` and `DiscreteLSTMTransformer` use sinusoidal positional encoding and a causal attention mask, while the hybrid model first processes the token embeddings with an LSTM and then applies a Transformer encoder.

## 5. Training Procedure

The discrete models are trained with cross-entropy next-token prediction. The logits `(B, T, C)` and targets `(B, T)` are flattened and passed to `F.cross_entropy`, so supervision is applied at every position in the sequence. The saved run uses:

- batch size `64`
- Adam optimizer
- learning rate `1e-3`
- `12` epochs
- gradient clipping with `max_norm = 2.0`

Printed training losses show steady optimization:

- Discrete RNN: `4.380498 -> 0.993823`
- Discrete LSTM: `4.473671 -> 1.472224`
- Discrete LSTM-Transformer: `4.232699 -> 0.085779`

The Gaussian notebook uses full-batch training with Adam and gradient clipping. The RNN and LSTM are trained with Gaussian negative log-likelihood for `250` iterations at learning rate `0.005`. The final executed `TR_extended` class also uses Gaussian negative log-likelihood. The saved training logs report:

- RNN: `1.411073 -> 0.131418`
- LSTM: `1.756535 -> 0.117281`
- Transformer: `1.881302 -> -0.468759`

## 6. Forecasting Method

The discrete notebook forecasts by sequential token sampling. Starting from a seed context, the model predicts logits at the final position, converts them to probabilities with `softmax`, samples the next token with `torch.multinomial`, appends that token, and repeats. The sampled future tokens are then converted back to continuous values through dequantization.

This makes the forecast generative rather than purely deterministic: each sampled token becomes part of the future conditioning sequence, so the rollout can branch into different trajectories.

The Gaussian notebook also performs autoregressive rollout, but it feeds sampled continuous values back into the model. Its saved evaluation uses `T_test = 100` and a forecast horizon of `H = 20`. The discrete notebook evaluates one-step prediction over the full test loader and long-horizon sampling with `horizon = T - T_train = 100`.

The discrete notebook reports one-step cross-entropy, one-step MSE after decoding back to continuous values, and autoregressive MSE from sampled forecasts:

| Discrete LSTM | 1.432115 | 0.062142 | 0.515349 |
| Discrete RNN | 0.982942 | 0.040340 | 0.672988 |

The Gaussian notebook reports:

| Model | One-step MSE | Horizon MSE (H=20) |

Several conclusions are directly supported by the saved outputs:

- the discrete formulation works end to end, including sampling-based forecasting
- among the discrete models actually trained, `DiscreteLSTMTransformer` performs best on both one-step and autoregressive metrics
- among the Gaussian baselines, the hybrid Transformer is best on one-step MSE, while the Gaussian LSTM is best on `H=20` forecasting MSE

One caveat matters: the long-horizon metrics are not directly comparable across notebooks because the discrete autoregressive MSE is reported at horizon 100, while the Gaussian horizon MSE is reported at 20.

## 8. Discussion

The main advantage of the discrete approach is representational flexibility. A categorical output over bins can approximate multimodal, asymmetric, and non-Gaussian uncertainty more naturally than a single Gaussian head. The tokenized formulation also aligns naturally with modern sequence-modeling architectures and autoregressive generation.

The tradeoffs are equally clear. Quantization introduces information loss, performance depends on bin resolution, and sampled rollouts add stochastic variance. The notebooks also show that simple recurrent discrete models are viable, but the strongest saved results come from the hybrid LSTM-Transformer, suggesting that combining local recurrence with richer contextual modeling is useful after tokenization.

## 9. Conclusion

This project implements a complete discrete probabilistic forecasting pipeline on the ETTh1 `OT` signal: normalization, uniform quantization into 128 bins, token-sequence modeling, cross-entropy training, autoregressive sampling, and decoding back to continuous values for evaluation. It also retains Gaussian autoregressive baselines built around RNN, LSTM, and a hybrid LSTM-Transformer.

The two notebooks therefore illustrate a clear conceptual progression. The original notebook follows the DeepAR-style view of forecasting as autoregressive probabilistic prediction with Gaussian outputs. The discrete notebook reformulates the same task as next-token generation over quantized signal states, connecting time-series forecasting to LLM-style sequence modeling while preserving probabilistic, autoregressive behavior.
